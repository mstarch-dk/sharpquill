## Typography Font Recommendations

The CMS uses one global font setting shared by the admin UI and public website.

Curated font options:

- `inter`: Default choice for balanced UI readability and broad language support.
- `manrope`: Modern geometric sans-serif for a cleaner, contemporary tone.
- `source-serif-4`: Serif option for editorial-style websites and long-form reading.
- `atkinson-hyperlegible`: Accessibility-focused option optimized for character distinction.

Tradeoff summary:

- Sans-serif options (`inter`, `manrope`, `atkinson-hyperlegible`) are typically stronger for dense admin interfaces.
- Serif option (`source-serif-4`) can improve reading feel on article-heavy websites, but may feel less compact in data-heavy admin screens.
- A single shared setting avoids mixed-font drift between admin and website and keeps branding consistent.
